# Launch plan: Plugin Studio

- Positioning: "Stop guessing which plugin to build. Rank gaps with live
  data, track traction daily, decide at day 30 against numbers you set first."
- Audience: indie plugin authors and small teams shipping several plugins.
- Channels: bundled into the Plugin Creator launch post (r/ClaudeCode, Show
  HN) as "the other half"; a follow-up post at day 30 publishing our own
  portfolio's real verdicts (the most credible demo there is).
- Listing text: "Plugin Studio -- portfolio analytics and gap radar for
  Claude plugin authors. Daily GitHub traffic beyond the 14-day window,
  day-30 verdicts, and a demand radar seeded with 46 ideas."
- Day-30 signal: 25+ outside users running traction on their own repos
  (visible as issues or stars from non-owners); stop if under 5.
